# Phase 4 Plan 01: Core OCR Engine & Pre-processing

**Wave:** 1
**Requirements:** OCR-01, OCR-03
**Dependencies:** None

## Goal
Implement a robust, client-side OCR recognition engine using `tesseract.js` with singleton worker lifecycle management, image downscaling, progress callbacks, and confidence scoring.

## Tasks
1. Create `client/src/lib/ocr/ocrEngine.ts`:
   - Implement `recognizeImage(imageSource, onProgress)` returning `{ text: string, confidence: number, lines: string[] }`.
   - Implement `downscaleImage(source, maxDimension)` ensuring canvas bounds <= 2048px.
   - Implement progress mapping (translates internal Tesseract progress 0..1 to percentage and user-friendly status message).
   - Implement worker reuse and lazy loading.
2. Create `client/src/lib/ocr/ocrEngine.test.ts`:
   - Unit tests covering downscaling calculations, confidence normalization, and text parsing.
3. Verification:
   - Run vitest on `ocrEngine.test.ts`.

## Deliverables
- `client/src/lib/ocr/ocrEngine.ts`
- `client/src/lib/ocr/ocrEngine.test.ts`
