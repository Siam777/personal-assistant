# Phase 4 Plan 03: Live Camera Stream & Frame Capture

**Wave:** 3
**Requirements:** OCR-02
**Dependencies:** 04-01-PLAN.md

## Goal
Implement a camera capture view utilizing the browser `mediaDevices.getUserMedia` API to stream video feed and grab high-resolution frame snapshots for OCR recognition.

## Tasks
1. Create `client/src/features/lens/CameraCaptureView.tsx`:
   - Requests camera access with `facingMode: "environment"` and ideal 1080p resolution.
   - Streams live video to `<video autoPlay playsInline muted />`.
   - Renders viewfinder targeting guide overlay.
   - "Capture Photo" button paints current frame to canvas and generates Blob.
   - Cleans up media stream tracks immediately on close/unmount (`track.stop()`).
   - Gracefully handles permission denied or camera missing errors.
2. Unit tests for camera helper functions and stream lifecycle in `client/src/features/lens/CameraCaptureView.test.ts`.

## Deliverables
- `client/src/features/lens/CameraCaptureView.tsx`
- `client/src/features/lens/CameraCaptureView.test.ts`
