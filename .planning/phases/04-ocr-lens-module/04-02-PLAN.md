# Phase 4 Plan 02: Image Ingestion (Dropzone, File Picker, Clipboard Paste)

**Wave:** 2
**Requirements:** OCR-01
**Dependencies:** 04-01-PLAN.md

## Goal
Build input components that allow users to upload images, drag and drop files from desktop/folders, or press Ctrl+V to paste screenshots directly into Lens.

## Tasks
1. Create `client/src/features/lens/ImageDropzone.tsx`:
   - Drag-and-drop zone with visual hover feedback.
   - File picker button.
   - Clipboard paste listener window event (`paste`) extracting image items from `event.clipboardData`.
   - File validation (checks mime type image/* and file size).
2. Create unit tests for image dropzone and file ingestion handlers in `client/src/features/lens/ImageDropzone.test.ts`.

## Deliverables
- `client/src/features/lens/ImageDropzone.tsx`
- `client/src/features/lens/ImageDropzone.test.ts`
