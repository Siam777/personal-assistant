# Phase 4 Plan 04: Lens UI Integration & Hub Navigation Switcher

**Wave:** 4
**Requirements:** OCR-01, OCR-02, OCR-03, OCR-04
**Dependencies:** 04-01-PLAN.md, 04-02-PLAN.md, 04-03-PLAN.md

## Goal
Build the unified Lens screen with editable text preview, 1-action copy, word/character statistics, confidence badge, and integrate module switching into `App.tsx`.

## Tasks
1. Create `client/src/features/lens/LensResultView.tsx`:
   - Split layout showing source image preview and full editable textarea.
   - 1-action CopyButton with toast confirmation.
   - Word count, character count, and OCR confidence indicator badge.
   - "Scan Another" / "Clear" buttons.
2. Create `client/src/features/lens/LensScreen.tsx`:
   - Coordinates state between Dropzone, Camera Viewfinder, Processing Progress, and Result View.
3. Update `client/src/App.tsx`:
   - Add Hub Navigation tab switching between **Vault** and **Lens (OCR)**.
   - Ensure Lens is fully functional both when Vault is unlocked and when Vault is locked.
4. Comprehensive typecheck and end-to-end unit tests.

## Deliverables
- `client/src/features/lens/LensResultView.tsx`
- `client/src/features/lens/LensScreen.tsx`
- `client/src/App.tsx` (updated with hub navigation)
