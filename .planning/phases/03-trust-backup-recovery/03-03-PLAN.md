# Plan 03-03: Encrypted Backup Export & Restore Engine

**Phase:** 3 — Trust, Backup & Recovery
**Wave:** 3
**Requirements:** BACKUP-01, BACKUP-02

## Goal
Implement a cryptographically authenticated, zero-plaintext backup engine that exports the full database as an AES-256-GCM + Argon2id encrypted snapshot (`.vaultbackup`), and transactionally restores the database from a backup file with full integrity verification.

## Tasks

1. **Backup Encryption & Packaging Module**
   - Create `server/src/modules/backup/backupCrypto.ts`:
     - `encryptBackup(payloadJson: string, passphrase?: string, defaultKey?: Buffer)`:
       - Uses Argon2id (or Master Key) to derive 32-byte key from salt.
       - Uses AES-256-GCM with fresh 12-byte CSPRNG IV.
       - Returns structured container object with version, format, exported_at, kdf params, and cipher payload.
     - `decryptBackup(container: EncryptedBackupContainer, passphrase: string)`:
       - Validates container format and version.
       - Derives decryption key with Argon2id using container's recorded salt and KDF params.
       - Decrypts and verifies 16-byte GCM authentication tag.
       - Throws detailed authentication/integrity error on any modification or wrong password.

2. **Backup Export & Restore Service**
   - Create `server/src/modules/backup/backupService.ts`:
     - `exportVaultData(db: Kysely<VaultDbSchema>)`:
       - Queries all entries (including active and soft-deleted), folders, tags, entry_tags, and audit_logs.
       - Encrypts via `encryptBackup`.
       - Emits `vault_exported` audit log event.
     - `restoreVaultData(db: Kysely<VaultDbSchema>, backupData: EncryptedBackupContainer, passphrase: string, mode: "replace" | "merge")`:
       - Decrypts and validates backup payload.
       - Validates payload structure using Zod `backupPayloadSchema`.
       - In atomic transaction `db.transaction().execute(async trx => ...)`:
         - If `mode === "replace"`: cleans out existing entries, folders, tags, entry_tags, and inserts all backup items.
         - If `mode === "merge"`: merges folders, tags, and inserts/updates entries.
       - Emits `vault_restored` audit log event.

3. **API Routes**
   - In `server/src/modules/backup/routes.ts`:
     - `POST /api/vault/backup/export` (supports optional `password`, downloads `.vaultbackup` json).
     - `POST /api/vault/backup/restore` (accepts backup container + `password` + optional `mode`).
   - Register routes in `server/src/app.ts`.

4. **Integration & Cryptographic Tests**
   - Create `server/src/modules/backup/backup.test.ts`:
     - Test full export with password.
     - Test restore into empty or existing vault.
     - Test wrong passphrase rejection without DB side effects.
     - Test ciphertext tampering / bit-flip rejection (GCM auth tag check).
     - Test roundtrip data integrity (all entry types, folders, tags).
