# Plan 03-04: UI Integration — Audit Log Viewer & Backup/Recovery Panels

**Phase:** 3 — Trust, Backup & Recovery
**Wave:** 4
**Requirements:** TRUST-01, TRUST-02, TRUST-03, BACKUP-01, BACKUP-02

## Goal
Build polished client UI components for Audit Log inspection and Encrypted Backup Export / Restore, integrating them seamlessly into the application navigation, with real-time feedback, toasts, and confirmation dialogs.

## Tasks

1. **Audit Log Modal & Viewer**
   - Create `client/src/features/vault-audit/AuditLogModal.tsx`:
     - Fetches logs from `GET /api/vault/audit`.
     - Supports event category filtering (All, Unlocks/Auth, Secret Access, Modifications, Backups).
     - Renders formatted cards/table with icons, badges, timestamp tooltip, IP/UserAgent info.
     - Clean empty state and refresh button.

2. **Backup & Restore Modal / Settings Panel**
   - Create `client/src/features/vault-backup/BackupModal.tsx`:
     - **Export Panel**:
       - Explanatory description.
       - Optional custom passphrase input.
       - "Export Encrypted Backup" button triggering download of `.vaultbackup` file.
     - **Restore Panel**:
       - File picker / drag & drop for `.vaultbackup` file.
       - Passphrase input.
       - "Replace" vs "Merge" selection.
       - Confirmation modal before replacing.
       - "Restore Vault" button with loading spinner.
       - Triggers data refetch and displays success toast.

3. **Navigation & Entry Detail Integration**
   - Add "Audit Log" and "Backup & Recovery" buttons/menu options to `App.tsx` / header toolbar.
   - Integrate 1-click Copy with 30s auto-clear in `EntryDetail.tsx` and toast notifications.

4. **End-to-End Verification**
   - Run typecheck and client build.
   - Run complete test suite across server and client.

## Verification
- `npm run typecheck && npm test` pass cleanly.
- Full UI and API integration verified.
