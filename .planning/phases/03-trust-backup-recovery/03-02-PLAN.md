# Plan 03-02: Clipboard 1-Action Copy & 30-Second Auto-Clear

**Phase:** 3 — Trust, Backup & Recovery
**Wave:** 2
**Requirements:** TRUST-01, TRUST-02

## Goal
Implement a 1-action copy mechanism for vault secrets with automatic clipboard clearing after 30 seconds and audit logging on copy/reveal.

## Tasks

1. **Client-Side Clipboard Utility / Hook**
   - Create `client/src/lib/clipboard.ts` or `client/src/features/vault-entries/useClipboardWithAutoClear.ts`:
     - Function `copySecretToClipboard(text: string, options?: { clearAfterMs?: number, onClear?: () => void })`
     - Writes to `navigator.clipboard.writeText(text)`
     - Sets a 30-second timer to clear clipboard if still holding copied text.
     - Tracks active timeout IDs and clears them on unmount or session lock.
     - Shows toast notification: "Copied to clipboard. Clearing in 30 seconds."

2. **CopyButton & Field Integration in EntryDetail**
   - Create `client/src/components/CopyButton.tsx` or enhance `EntryDetail.tsx` secret fields.
   - For all secret fields (API Key, Password, Card Number, CVV, Note Body):
     - Provide a clear 1-click Copy button.
     - When clicked, copy the unmasked secret value to clipboard, trigger auto-clear timer, and notify the backend of `secret_copied` event (`POST /api/vault/audit/events`).
     - When reveal button is toggled, notify the backend of `secret_revealed` event.

3. **Session Lock Cleanup**
   - When the vault locks (auto-lock or manual lock), any active clipboard auto-clear timers immediately clear clipboard if armed.

4. **Testing**
   - Unit tests for clipboard auto-clear logic and audit event dispatch.

## Verification
- Client build and typecheck succeed.
- Tests verify clipboard write, timer trigger, and clear dispatch.
